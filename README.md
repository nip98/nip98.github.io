# nip98.com

Landing page and documentation for [NIP-98](https://github.com/nostr-protocol/nips/blob/master/98.md) — HTTP Auth for Nostr.

**Live site:** [nip98.com](https://nip98.com)

## For Developers & LLMs

See **[SKILL.md](SKILL.md)** — a complete implementation guide with zero-dependency
client code, server validation middleware, and drop-in integration recipes.

Assumes [NIP-07](https://github.com/nostr-protocol/nips/blob/master/07.md) keys
via `window.nostr` (e.g. nos2x, Alby, [nostr-login](https://nip-07.github.io/nip7/)).
